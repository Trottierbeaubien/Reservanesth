Installer RéservAnesth sur mon iPhone

Une seule installation, sans App Store.

  1. Ouvrez cette page dans Safari.
  2. Dans le menu de Safari, touchez Partager (le carré avec une flèche vers le haut), puis Sur l’écran d’accueil. Selon votre version, ce choix peut se trouver dans « Plus ».
  3. Touchez Ajouter, puis ouvrez la nouvelle icône RéservAnesth.
  4. Connectez-vous. Dans Notifications, touchez Activer sur cet appareil, puis Autoriser.

Nécessite iOS 16.4 ou ultérieur. Les notifications s’activent depuis l’application installée.
